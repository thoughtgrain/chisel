# Sources

Hardware facts in these docs come from these pages, as of Oct 28, 2026.

## MPC Sample

- [Synth Anatomy: Akai opens its MPC Sample sampler to the community for custom firmwares](https://synthanatomy.com/2026/10/akai-mpc-sample-hardware-sampler-inspired-by-the-mpc60-and-mpc3000.html). Open-firmware announcement, specs, firmware 1.3 takeover modes.
- [Sound On Sound: Akai MPC Sample review](https://www.soundonsound.com/reviews/akai-mpc-sample). Layout, function buttons and knobs, takeover behavior.
- [Gearnews: AKAI MPC Sample review](https://www.gearnews.com/akai-mpc-sample-review/). Control layout, firmware 1.3, knob resolution.

- [Torso Electronics](https://torsoelectronics.com/). Please support them if you like the S-4.
- [Thomann: Torso Electronics S-4](https://thomann.ae/torso_electronics_s_4.htm). Signal chain, granular buffer, filter bank, encoder and button counts.
- [Signal Sounds: Torso S4](https://www.signalsounds.com/torso-s4-sculpting-sampler-white). Perform page macros, modulators.
- [Splice: The Torso S-4 sculpting sampler, a complete guide](https://splice.com/blog/?p=36800). Device overview, modulators.
